HTML VS CSS

Same Goal. Different Jobs! ✨

HTML gives a website its structure. CSS makes it beautiful!

🧡 HTML

The Structure

HTML stands for HyperText Markup Language. It creates the basic structure of a webpage.

Key Tags

<html> <head> <body> <h1> <p> <div>
💡 Think of HTML as the skeleton of a website!

💙 CSS

The Style

CSS stands for Cascading Style Sheets. It adds colours, fonts, spacing and layouts.

Key Properties

color background font-size margin padding border
🎨 Think of CSS as the outfit of a website!

HTML + CSS = Beautiful Websites 💖
